# LocaScore

Интерактивная карта доступности инфраструктуры для Польши и Беларуси. Поиск адресов, объекты поблизости, расстояния и предварительная оценка доступности на основе OpenStreetMap. Интерфейс: польский, английский, белорусский и русский.

## Как работает

Приложение работает в браузере. Собственный backend, Firebase, база данных и API-ключи не требуются.

- Карта: тайлы OpenStreetMap.
- Поиск адресов: публичный Photon (`photon.komoot.io`).
- Объекты окружения: Overpass (`maps.mail.ru`, резервный `overpass.kumi.systems`).
- Геометрия, расстояния и рейтинг: локальные вычисления в браузере.
- Границы стран: включённые GeoJSON-файлы из OSM; происхождение и даты указаны в `public/data/boundaries/source.json`.

**Интернет необходим.** Адрес поиска отправляется Photon, координаты выбранного места — провайдеру Overpass, а запросы карты — серверу тайлов. Эти сервисы также получают обычные сетевые сведения, включая IP-адрес. Приложение не содержит собственного сервера хранения запросов. Настройки интерфейса могут сохраняться в localStorage браузера.

Публичные сервисы могут ограничивать запросы или быть недоступны. При ошибке приложение показывает ошибку, а не демонстрационные результаты. Для большого трафика понадобятся подходящие провайдеры или собственная инфраструктура. Правила тайлов: https://operations.osmfoundation.org/policies/tiles/ ; Photon: https://github.com/komoot/photon .

## Локальный запуск

Нужны Node.js 22.22.3+ в ветке 22, Node.js 24.15.0+ в ветке 24 или Node.js 26+, а также npm. Рекомендуется поддерживаемая LTS-версия Node.js.

```sh
npm ci
npm start
```

Откройте http://localhost:4200 . Запускайте через HTTP-сервер, а не двойным щелчком по HTML.

## Проверки и сборка

```sh
npm run typecheck
npm test
npm run build
```

Результат: `dist/locascore/browser/`. Angular формирует рядом с ним `dist/locascore/3rdpartylicenses.txt`; при размещении сайта сохраните этот файл с уведомлениями библиотек.

`npm test` проверяет поиск, кэш, конвертацию OSM, расстояния и обработку недоступности на контролируемых ответах. Это не полная проверка интерфейса и не подтверждение доступности внешних сервисов.

## Публикация исходников на GitHub

Загрузите содержимое этой папки в корень отдельного репозитория. `node_modules`, `.angular`, `dist`, локальные настройки и секреты исключены через `.gitignore`. Значение `private: true` в `package.json` защищает от случайной публикации пакета в npm и не мешает публичному репозиторию GitHub.

В `.github/workflows/ci.yml` настроены установка по lock-файлу, проверки и сборка. Этот процесс не публикует сайт автоматически.

## Размещение сайта на GitHub Pages

Для репозитория `locascore` соберите:

```sh
npm run build -- --base-href /locascore/
```

Для другого имени репозитория замените `/locascore/` соответствующим путём. Для сайта в корне домена используйте `/`. Опубликуйте содержимое `dist/locascore/browser/` выбранным способом GitHub Pages, добавив туда `dist/locascore/3rdpartylicenses.txt`. Не публикуйте всю папку проекта как готовый сайт.

## Ограничения оценки

Рейтинг — эвристика доступности ближайших объектов, а не оценка качества жилья, медицины или образования. Расстояния геодезические до геометрии объектов, а не маршруты пешком. Отсутствие объекта в OSM не доказывает его отсутствие на местности. Полнота данных неизвестна. Правила и веса находятся в `src/shared/analysis/rating.ts`.
